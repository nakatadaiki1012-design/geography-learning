# 地理ラボ

地理総合・地理探究の授業で使える、**地図を見て、動かして、考える**Webアプリです。
`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで動きます（インストール不要）。
地図のデータと部品（d3・topojson）は `vendor/` フォルダに入っているので、**インターネットがなくても動きます**（見出しのフォントだけはネットから読み込みます）。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/geography-learning/

> GitHub Pages の有効にし方：GitHub のこのリポジトリ → Settings → Pages → 「Branch」で `main` と `/ (root)` を選んで Save。数分後に上のURLで開けます。

## 画面の構成

画面上は **見る／動かす／挑戦／授業モード** の4つ（分子ラボ3Dと同じ構成）。

| モード | 中身 |
|---|---|
| 見る | 地球儀と図法・気候・統計地図（GIS）・地形と災害 |
| 動かす | 時差・地形図を読む・防災シミュレーション・人口ピラミッド |
| 挑戦 | 資料読み取り（共通テスト型）・白地図クイズ |
| 授業モード | 地理総合 16 授業・地理探究 18 授業（学習指導要領の順） |

## パソコン・Chromebook で使うとき

- どの画面も**ページ全体をスクロールしなくても1画面に収まる**ようにしています（1366×657 や 1280×600 の画面で確認）。
- 上のバーは1行、右の説明は見出しごとの**タブ**に分かれています。
- 授業のスライドは画面の高さに合わせて、図が自動で大きさを変えます。
- 確認テストと資料読み取りは、左に問題と選択肢、右に解説と図が出ます。

## スマホで使うとき

- 地図やグラフを上、説明を下に置き、**ページ全体をスクロールしなくても1画面に収まる**ようにしています。
- 説明は「説明／ランキング／考えよう」などの**タブ**に分かれています。タブを押して切りかえます。
- 授業の一覧は大項目ごとにたたんであり、次に学ぶ大項目だけが開きます。

## 見る

- **地球儀と図法**：地球儀（ドラッグで回る）、メルカトル・正距方位・モルワイデ・サンソン・正距円筒・心射図法を切りかえ。
  - 「ゆがみの円」：同じ大きさの円が図法によってどうゆがむかが見える（高緯度で大きくなるメルカトル図法など）。
  - 2都市を選ぶと、**大圏航路（最短コース・赤）**と**等角航路（緑）**、距離と方位を表示。
  - 正距方位図法で「出発地から東西南北」：東京から真東に進むと南アメリカに着くことが確かめられる。
- **気候**：世界22都市の雨温図・ハイサーグラフ。ケッペンの判定の流れ（乾燥限界 r の計算もふくむ）を1段ずつ表示。2都市を重ねてくらべられる（ロンドンと東京など）。
  - 「自分で判定する」：名前をかくした都市の雨温図を読み、判定の質問に はい／いいえ で答えて気候区を当てる。
- **統計地図（GIS）**：48か国の統計（人口・面積・人口密度・1人当たりGNI・合計特殊出生率・65歳以上の割合・都市人口率・CO₂排出量・主な宗教）を地図にする。
  - 「階級区分図」と「図形表現図」を切りかえ。**絶対値を階級区分図にすると「誤解をまねく」と警告**が出る（地図の表し方を考える学習）。
  - 地域ごとにズーム（地誌の学習用）、ランキング表。
  - 「散布図」：2つの統計の関係（所得と出生率など）と相関係数。
- **地形と災害**：新期造山帯・古期造山帯・安定陸塊・プレート境界・火山・大地震を地図に重ねる。日本付近の4枚のプレートと海溝・トラフ。
  - プレート境界（広がる・沈みこむ・ぶつかる・ずれる）の動く模式図。

## 動かす

- **時差**：時刻のスライダーを動かすと、昼と夜の境目・太陽が真上の地点・各都市の時刻が変わる。季節（夏至・冬至など）も変えられる。日付変更線つき。2都市の時刻の計算（計算式つき）、飛行機の到着時刻の問題（毎回変わる）。
- **地形図を読む**：尾根と谷・扇状地・火山・河岸段丘・三角州の架空の地形図（等高線・計曲線・縮尺つき）。
  - 地図を2回クリックすると**断面図**（たての倍率を変えられる）。
  - 「P 地点を出す」：等高線から標高を読み取る練習。2万5千分の1／5万分の1の切りかえ。
- **防災シミュレーション**：架空の町（山地・扇状地・川・自然堤防・後背湿地・旧河道・台地・海岸）で、洪水・津波・土砂災害のハザードマップを表示。
  - 水位や津波の高さのスライダーで浸水の範囲と深さが変わる。
  - 避難所 A〜E を選ぶと、**自宅からの道すじ**（浸水した所をさけた道）と、避難所としての評価（浸水の深さ・階数・道のり）が出る。
- **人口ピラミッド**：日本（2020年国勢調査のおおよその値）・エチオピア・アメリカ・中国・アラブ首長国連邦。
  - 合計特殊出生率・平均寿命・人口移動のつまみを動かして「5年進める」と、将来の人口ピラミッドを予測。総人口と老年人口の割合のグラフ。
  - 型（富士山型・つりがね型・つぼ型・星型）を自動で判定。

## 挑戦

- **資料読み取り**：1回10問。毎回問題が変わる。
  - 雨温図と地図から都市を当てる／統計表（ア〜エ）から国を当てる／主題図の表し方を選ぶ／時差の計算／人口ピラミッドから国を当てる／思考・判断の問題。
  - 解説では「どの資料のどこが根拠になるか」を示す。
- **白地図クイズ**：国名を見て地図上の国をクリック。きほん（48か国）・たくさん（110か国）、地域でしぼれる。拡大・移動できる。

## 授業モード

- 学習指導要領の項目の順に並ぶ。
  - **地理総合**（16授業）：A 地図や地理情報システムで捉える現代世界／B(1) 生活文化の多様性と国際理解／B(2) 地球的課題と国際協力／C 持続可能な地域づくりと私たち
  - **地理探究**（18授業）：A 系統地理（自然環境・資源と産業・交通と観光・人口と都市・生活文化）／B 地誌（地域区分と東アジア〜南北アメリカ・オセアニア）／C これからの日本の国土像
- 各授業は **問い → ① 説明 → ② 資料で考える → ③ 考えよう → ④ 確認テスト** の流れ。
  - ① 説明：**すべてのスライドに地図・グラフ・模式図**（図法、雨温図、プレート、地形の断面、人口ピラミッド、主題図など）。パソコンでは文章の横、スマホでは文章の上に出る。
  - 図は**さわって動かせる**（ボタンは増やさず、図そのものをなぞる・さわる。図の右上に「↔ なぞる」などの小さな目印）：地球儀・図法はドラッグで回す／緯度経度の地球儀はさわるとその場所の緯度経度／時差の地図は横になぞると昼と夜が動く／大気の大循環は上下になぞると季節が変わり気圧帯が動く／地形図は A・B を動かすと断面図が変わり、さわると標高／人口ピラミッドは横になぞると2100年までの変化／氾濫原やハザードマップの模式図は水位を上下に動かせる／縮尺は目盛りを動かすと実際の距離／人口転換は時代を動かせる／雨温図は月をさわると数値／地図の国や都市をさわると名前や統計（気候帯の地図は都市をさわると雨温図）。
  - ④ 確認テスト：答えたあとの**解説にも地図や図**が出る（答えの国や地域を地図でぬる、関係する雨温図や模式図など）。
  - ② 資料で考える：その授業に合わせた道具（地図・グラフ）が授業の画面の中で動く。
  - ③ 考えよう：**思考・判断・表現**のための記述問題。使う「地理的な見方・考え方」（位置や分布・場所・人間と自然環境との相互依存関係・空間的相互依存作用・地域）を表示。書いた答えは自動で保存。「解答例とふりかえり」で解答例と自己評価のチェックリスト。
  - ④ 確認テスト：4問。3問以上で合格のはんこ。
- 一覧には見た授業に ✓、合格した授業にはんこ。「続きから」で次の授業へ。キーボードの ← → でスライドを進められる。

## 「考えよう」（思考・判断・表現）について

各道具の右側と各授業に「考えよう」カードがあります。
「資料から読み取ったこと（根拠）→ 考えたこと（理由）→ 結論」の順に書くように案内し、解答例のあとに次のふりかえりをします。

- 資料（地図・グラフ・統計）から読み取ったことを根拠にした
- 「なぜそうなるのか」を自然環境や人の活動と結びつけた
- 結論をはっきり書いた

書いた内容は、その端末のブラウザの中だけに保存されます（先生には送られません）。

## 先生向けメモ

- 統計の数値は、傾向をつかむための**おおよその値**（おもに2022〜2023年ごろ）です。定期テストや入試の前には、最新の統計（『データブック オブ・ザ・ワールド』『世界国勢図会』など）で確かめてください。
- 雨温図の値は各都市の平年値のおおよその値です。昭和基地の降水量は観測がむずかしいため目安の値です。
- 気候区分は高校の教科書の判定方法（乾燥限界 r = 20t ／ 20(t+7) ／ 20(t+14)）で計算しています。キトは判定では Cfb になりますが、高山気候として表示しています。
- プレート境界・造山帯の線は、おおよその位置を示す模式です。
- 地形図・防災シミュレーションの町は**架空の地形**です。実際の地域の学習には、国土地理院の「地理院地図」や市町村のハザードマップを使ってください。
- 人口ピラミッドの予測は、出生率・平均寿命・人口移動から計算する簡単なモデルです（日本の2020年の形は国勢調査のおおよその値）。

## ファイルの構成

```
index.html            画面の骨組みと見た目
js/data.js            国の統計・都市の気候データ
js/core.js            共通の部品（地図・雨温図・ケッペンの判定・考えようカードなど）
js/tool-*.js          それぞれの道具（図法・気候・統計地図・地形・時差・地形図と防災・人口）
js/challenge.js       資料読み取り・白地図クイズ
js/lessons.js         授業の中身（地理総合）
js/lessons-tankyu.js  授業の中身（地理探究）
js/figures.js         授業やテストの図（地図・グラフ・模式図）をつくる部品
js/fig-interact.js    図をさわって動かせるようにする部品
js/lesson-figs.js     どの授業のどのスライド・問題にどの図を出すか
js/lesson-view.js     授業モードの画面
js/main.js            画面の切りかえ
vendor/               地図を描く部品（d3、topojson-client）と世界地図のデータ（world-atlas）
```

授業の文章や問題を直したいときは `js/lessons.js`（地理総合）、`js/lessons-tankyu.js`（地理探究）を開いて、文字を書きかえれば反映されます。
